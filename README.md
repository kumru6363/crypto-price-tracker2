# Crypto Price Tracker 2

Basit bir Python CLI aracı — CoinGecko API ile kripto para fiyatlarını çeker ve terminalde gösterir.

## Kurulum

1. Python 3 yüklü olmalı.
2. Gerekli paketleri yükle:
```bash
pip install -r requirements.txt
```

## Kullanım

Python script’i çalıştır:
```bash
python crypto_price_tracker.py
```

Desteklenen coinler: bitcoin, ethereum, dogecoin (kod içinde listelenmiş)
